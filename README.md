Expense Tracker Application
A full-stack financial management web application built with Django that helps users take control of their personal finances. The application provides secure user authentication, detailed transaction logging, real-time budget analytics, and interactive savings goal tracking.

Key Features
User Authentication & Privacy: Secure registration, login, and session management ensuring user data remains private and strictly isolated.

Transaction Management: Complete logging system to record income and expenses with detailed attributes (title, amount, transaction type, date, and category).

Financial Analytics Dashboard: Real-time calculation and visualisation of total income, total expenses, net savings, and financial progress.

Savings Goal Tracking: Dedicated goal-setting module where users set target amounts and deadlines, tracking target completion percentages directly on the dashboard.

Structured Data Views: Dedicated transaction history page with server-side querying for clear record reviewing and tracking.
